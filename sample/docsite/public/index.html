为什么选择 codeone

为人类与 AI 同时设计的系统语言

没有隐藏的默认值，没有类型推导的猜测。每一行 SSA 都只表达一件事，编译器与读者看到的是同一份事实。

极简 SSA

38 条指令覆盖算术、内存、原子操作、控制流、调用与内联汇编。语法固定，看到关键字就能确定整行结构。

标准库 Box

套接字、HTTP/WebSocket、TLS 1.2/1.3、AES、SHA、RSA、P-256、JSON、文件系统、线程与数据结构，以可组合的 .bx 模块提供。

原生性能

直接降低到 LLVM IR，-O2 生成目标平台机器码，无虚拟机、无运行时解释开销。

硬件加速密码学

AES、SHA-256 与 GHASH 在 ARMv8 Crypto 与 AES-NI 上直接调用硬件指令，TLS 握手与批量加密都不妥协。

跨平台

平台库封装 BSD sockets、kqueue / epoll、CSPRNG 与 CPU 特性检测，同一份 SSA 面向 macOS 与 Linux。

面向 AI 的语法

模式复用、严格固定、单前缀约定，让 LLM 能以更高准确率生成和修改 SSA 代码。

工作流

从一行 SSA 到可执行文件

一个编译器驱动完成编译与链接，标准库模块按需传入。

01

编写 .bx

用 SSA 描述函数、结构体与全局数据。每个基本块以 jmp、br 或 ret 结束。

02

链接 Box

需要什么就传入什么：io/print.bx、net/socket.bx、crypto/sha.bx。

03

c1 编译

SSA 先降低为 LLVM IR，-O2 优化后交给系统链接器，产物是原生可执行文件。

终端
$ ~/.codeone/toolchain/bin/c1 main.bx \
    ~/.codeone/toolchain/boxes/std/io/print.bx \
    -O2 -o app
$ ./app
